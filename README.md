# ระบบสแกนเครื่องในวงแลน (LAN IP & Port Scanner)

โปรแกรม Desktop GUI บน Windows พัฒนาด้วย Python มาตรฐาน (`tkinter` + Windows `iphlpapi`) ไม่ต้องติดตั้งไลบรารีภายนอกเพิ่มเติม

## ฟีเจอร์หลัก
- **กำหนดช่วง IP ได้หลายรูปแบบ**
  - ระบุ `IP เริ่มต้น` และ `IP สิ้นสุด` (เช่น `192.168.1.1` ถึง `192.168.1.254` หรือใส่เฉพาะเลขหลักท้าย เช่น `50`)
  - รองรับรูปแบบย่อในช่องเริ่มต้น เช่น CIDR (`192.168.1.0/24`), ช่วงขีด (`192.168.1.10-80`) หรือคั่นด้วยลูกน้ำ (`192.168.1.1-20, 192.168.1.100-120`)
  - ดึงรายการการ์ดแลนในเครื่องอัตโนมัติ (รองรับเครื่องที่มีหลายวงแลนพร้อมกัน)
- **ข้อมูลอุปกรณ์ครบถ้วน**
  - ตรวจจับสถานะ Online แม่นยำด้วย **ARP + ICMP Ping + TCP Probe** (เจอเครื่องแม้เปิด Windows Firewall บล็อก Ping)
  - ดึงชื่อเครื่อง (**Hostname / Workgroup**) ผ่าน NetBIOS (UDP 137), Reverse DNS และ mDNS (`.local`)
  - แสดง **MAC Address**, **ยี่ห้ออุปกรณ์ (Vendor OUI)**, **เวลาตอบสนอง (Ping)** และจำแนกประเภทอุปกรณ์
- **สแกนพอร์ตบริการ (TCP Port Scan)**
  - มีชุดพอร์ตมาตรฐานให้เลือก (SSH 22, HTTP 80, HTTPS 443, SMB 445, RDP 3389, Printer 9100, RTSP 554 ฯลฯ) และแก้ไขพอร์ตเองได้
- **เครื่องมือจัดการด่วน & ส่งออกไฟล์**
  - คลิกขวาหรือกดปุ่มด่วนเพื่อ คัดลอก IP/MAC, เปิดหน้าเว็บ, เชื่อม Remote Desktop (RDP), เปิดโฟลเดอร์แชร์ (`\\IP`)
  - บันทึกผลลัพธ์เป็นไฟล์ **CSV (รองรับภาษาไทยใน Excel)** และ **JSON**

## วิธีเปิดใช้งาน
1. **ดับเบิลคลิกไฟล์** `run_scanner.bat` หรือ `LAN_Scanner.pyw` เพื่อเปิดหน้าต่างโปรแกรมทันที (ไม่มีจอดำค้าง)
2. หรือรันผ่าน Terminal:
   ```powershell
   python main.py
   ```
3. โหมดทดสอบผ่าน Command Line:
   ```powershell
   python main.py --cli 192.168.1.1 192.168.1.50
   ```
